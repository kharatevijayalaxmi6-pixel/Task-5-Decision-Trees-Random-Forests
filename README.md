# Task 5: Decision Trees and Random Forests

## Objective
Learn tree-based models for classification and understand ensemble learning.

## Dataset
Breast Cancer Wisconsin Dataset from Scikit-learn.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Loaded and explored the dataset.
2. Checked for missing values.
3. Split the dataset into training and testing sets.
4. Trained a Decision Tree Classifier.
5. Visualized the Decision Tree.
6. Analyzed overfitting and controlled tree depth.
7. Trained a Random Forest Classifier.
8. Compared model accuracy.
9. Analyzed feature importance.
10. Performed 5-fold cross-validation.

## Results

| Model | Testing Accuracy |
|---|---:|
| Decision Tree | 91.23% |
| Limited Decision Tree | 93.86% |
| Random Forest | 95.61% |

Random Forest Cross-Validation Accuracy: 95.61%

## Conclusion
Random Forest achieved the highest testing accuracy among the three models. This task helped me understand Decision Trees, Random Forests, overfitting, feature importance, and cross-validation.
